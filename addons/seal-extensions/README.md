# bowerbird-seal-extensions

The optional parts of sealing for bowerbird-mcp: several signers, a quorum and a seal count: an add-on for [bowerbird-mcp](https://github.com/dfoulks1/bowerbird-mcp).

```sh
pip install 'bowerbird-mcp[seal-extensions]'
```

Set `seal: {extensions: true}` in `bower.yaml`.

Documentation: https://bowerbird.voltpop.com/sealing/

Problems: https://github.com/dfoulks1/bowerbird-mcp/issues or dfoulks@voltpop.com.

Apache-2.0. The version is the one of bowerbird-mcp it is released with.
