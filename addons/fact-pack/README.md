# bowerbird-fact-pack

More kinds of fact for bowerbird-mcp: key, git, until, manual and script: an add-on for [bowerbird-mcp](https://github.com/dfoulks1/bowerbird-mcp).

```sh
pip install 'bowerbird-mcp[fact-pack]'
```

A page then uses the kinds in `[fact.KIND]` blocks.

Documentation: https://bowerbird.voltpop.com/fact-pack/

Problems: https://github.com/dfoulks1/bowerbird-mcp/issues or dfoulks@voltpop.com.

Apache-2.0. The version is the one of bowerbird-mcp it is released with.
