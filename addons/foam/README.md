# bowerbird-foam

A Foam workspace as a bowerbird-mcp collection: an add-on for [bowerbird-mcp](https://github.com/dfoulks1/bowerbird-mcp).

```sh
pip install 'bowerbird-mcp[foam]'
```

Set `format: foam` in `bower.yaml`.

Documentation: https://bowerbird.voltpop.com/formats/foam/

Problems: https://github.com/dfoulks1/bowerbird-mcp/issues or dfoulks@voltpop.com.

Apache-2.0. The version is the one of bowerbird-mcp it is released with.
