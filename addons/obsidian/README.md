# bowerbird-obsidian

An Obsidian vault as a bowerbird-mcp collection: an add-on for [bowerbird-mcp](https://github.com/dfoulks1/bowerbird-mcp).

```sh
pip install 'bowerbird-mcp[obsidian]'
```

Set `format: obsidian` in `bower.yaml`.

Documentation: https://bowerbird.voltpop.com/formats/obsidian/

Problems: https://github.com/dfoulks1/bowerbird-mcp/issues or dfoulks@voltpop.com.

Apache-2.0. The version is the one of bowerbird-mcp it is released with.
